# AtliQ Hardwares – Finance & Supply Chain Analytics

##  Project Overview

This project analyzes AtliQ Hardwares' **sales, customers, products, markets, and supply chain data** using SQL. The goal was to find useful business insights and support better decision-making.

##  Tools Used
* MySQL – Data analysis and SQL queries
* GitHub – Project documentation and sharing

##  Analysis Performed

* Product-wise and monthly sales analysis
* Top 5 products by net sales
* Top 5 markets by net sales
* Top 5 customers by net sales
* Customer-wise net sales contribution
* APAC region sales analysis
* Top 3 products by quantity in each division
* Supply chain forecast accuracy

##  Key Insights

* Amazon had the highest net sales at **109.03M** in FY2021.
* India had the highest APAC net sales at **210.67M**.
* Amazon contributed **13.23%** of total customer net sales.
* AQ Gamers Ms had the highest quantity among the identified top products.

##  SQL Concepts Used

`SELECT` · `JOIN` · `WHERE` · `GROUP BY` · `ORDER BY` · `CTE` · `Window Functions` · `DENSE_RANK()` · Aggregate Functions
